
# 📘 Assignment: Jogo da Forca

## 🎯 Objective

Construir uma versão em Python do jogo da forca para praticar manipulação de strings, estruturas de repetição, condicionais e entrada do usuário.

## 📝 Tasks

### 🛠️ Implementar o jogo básico

#### Description
Implemente a lógica principal do jogo da forca: escolha aleatória de palavra, loop principal de jogo, recepção de palpites do usuário, exibição do estado atual da palavra (por exemplo: _ a _ _ a _), controle de tentativas restantes e mensagens de vitória/derrota.

#### Requirements
Completed program should:

- Selecionar palavras aleatoriamente a partir de uma lista pré-definida
- Aceitar palpites de letras e atualizar a exibição do progresso (formato: _ _ _ )
- Rastrear e exibir o número de tentativas incorretas restantes
- Finalizar quando a palavra for descoberta ou as tentativas se esgotarem
- Exibir mensagens claras de vitória e derrota


### 🛠️ Melhorias opcionais

#### Description
Implemente uma ou mais melhorias opcionais para tornar o jogo mais completo ou configurável.

#### Requirements
Completed program should (choose at least one):

- Carregar a lista de palavras a partir de um arquivo (por exemplo, `words.txt`)
- Adicionar níveis de dificuldade que ajustem o número de tentativas ou o conjunto de palavras
- Permitir que o jogador jogue múltiplas rodadas e acompanhar pontuação simples
- Tratar entradas inválidas (caracteres repetidos, entradas vazias) com mensagens apropriadas
