# 📘 Assignment: Algorithms and Data Structures in Python

## 🎯 Objective

Learn how to solve common programming problems using Python lists, dictionaries, and search algorithms. This assignment builds algorithmic thinking by combining data processing, frequency counting, and efficient lookups.

## 📝 Tasks

### 🛠️ Task 1: Work with Lists and Number Sequences

#### Description
Use list operations to filter, sort, and simplify number sequences. This task teaches you how to manipulate lists and prepare data for algorithmic processing.

#### Requirements
Completed program should:

- Define a function `filter_even_numbers(numbers)` that returns only even numbers from the input list
- Define a function `sort_descending(numbers)` that returns the input numbers sorted from highest to lowest
- Define a function `unique_numbers(numbers)` that returns a list with duplicates removed while preserving the original order
- Include example input and output in the README or comments

### 🛠️ Task 2: Build a Word Frequency Counter

#### Description
Use a Python dictionary to count how often each word appears in a text. This task teaches you how to store and look up data efficiently using key-value pairs.

#### Requirements
Completed program should:

- Define a function `count_word_frequency(text)` that returns a dictionary mapping each word to its frequency
- Normalize text to lowercase and ignore punctuation when counting words
- Return counts for all distinct words in the text
- Provide an example of the function working on a sample sentence

### 🛠️ Task 3: Implement Search Algorithms

#### Description
Create simple search functions to find values in a list. This task introduces algorithm design and shows when different search methods are useful.

#### Requirements
Completed program should:

- Define a function `linear_search(numbers, target)` that returns the index of `target` in `numbers`, or `-1` if not found
- Define a function `binary_search(numbers, target)` that works on a sorted list and returns the index of `target`, or `-1` if not found
- Include example usage demonstrating both search functions
- Explain the difference in how the two searches work in the comments
